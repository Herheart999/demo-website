#  ข้อมูลเกี่ยวกับ Grok
---

## ข้อมูลสำคัญ (Ingested)

- **xAI และพันธกิจ:** xAI เป็นบริษัทด้านปัญญาประดิษฐ์ (AI) ที่มีเป้าหมายในการผลักดันการทำความเข้าใจจักรวาลและการค้นพบทางวิทยาศาสตร์
- **การร่วมมือกับ SpaceX:** ข้อมูลระบุว่า SpaceX ได้ควบรวม/ดึงตัว xAI เข้าร่วมเพื่อเร่งขับเคลื่อนวิสัยทัศน์ในอนาคตของมนุษยชาติ
- **รู้จักกับ Grok:** Grok คือแบบจำลองปัญญาประดิษฐ์หรือ AI Chatbot ที่ถูกเรียกเปรียบเปรยว่าเป็น "ไกด์นำทางระดับจักรวาล" สามารถเข้าถึงได้ผ่าน grok.com รวมถึงแอปพลิเคชันบน iOS และ Android
- **สำหรับนักพัฒนา (Developer API):** xAI มีบริการ API ที่คอนโซล [console.x.ai](https://console.x.ai/) และเปิดตัวเอกสารคู่มือ [Developer Docs](https://docs.x.ai/) ให้นักพัฒนาสามารถนำ Grok ที่มีความโดดเด่นด้านความเร็ว ความแม่นยำ และรองรับหลากหลายภาษา ไปฝังเป็นหัวใจหลักในแอปพลิเคชันของตนเองได้
